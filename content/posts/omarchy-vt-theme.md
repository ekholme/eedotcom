For the presumably very small subset of people out there who are both Omarchy users and Hokies, I've got you covered.

Check out the [Virginia Tech theme for Omarchy](https://github.com/ekholme/omarchy-virginia-tech-theme). You can install it like so:

`omarchy theme install https://github.com/ekholme/omarchy-virginia-tech`
