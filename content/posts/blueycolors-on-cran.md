As of a few days ago, [{blueycolors}](https://github.com/ekholme/blueycolors) – an R package I created that provides Bluey-inspired color palettes and ggplot scale functions – is on CRAN. Although I’ve been coding in R for about a decade, this is the first package I’ve ever submitted to CRAN. The short version is that it was much easier than I thought it would be – I just followed the steps outlined in in the Github issue created by `usethis::use_release_issue()`, made sure to read the output of all of the checks, and addressed any errors or notes that popped up. I didn’t even need to recruit an AI buddy to help me out. The whole process was incredibly mundane and straightforward and not at all as intimidating as I (for whatever reason) anticipated.

So if you’re considering submitting something to CRAN, do it! I’m happy I did.
